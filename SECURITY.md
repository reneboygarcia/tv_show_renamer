# Security policy

## Supported versions

Only the latest commit on `main` gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub instead:

1. Go to the [Security tab](https://github.com/reneboygarcia/tv_show_renamer/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps to reproduce it.

You can also open the [private report form](https://github.com/reneboygarcia/tv_show_renamer/security/advisories/new) directly.
